# Food Delivery Data Analysis Using Python

## Project Overview
Exploratory Data Analysis (EDA) of food delivery data using Python to understand order trends, vendor revenue, delivery delays, weather conditions, and delivery times.

## Objectives
- Analyze city-wise order distribution.
- Explore vendor revenue and order values.
- Study weather conditions and delivery delays.
- Analyze delivery time and distance.
- Visualize patterns using charts.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Report
The complete analysis, charts, and conclusions are available in the PDF report in this repository.

## Key Analysis
- City-wise order count
- Vendor revenue analysis
- Weather and delivery delays
- Delivery-time categories
- Delivery distance vs. delivery time
- Daily order distribution
- Monthly order value
